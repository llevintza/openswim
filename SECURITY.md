# Security Policy

## Supported versions

OpenSwim is in early development (Phase 0 scaffold). Security fixes apply to the
default branch (`main`) as the project evolves.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Prefer one of these private channels:

1. **GitHub Security Advisories** — use *Security → Report a vulnerability* on
   the [openswim](https://github.com/llevintza/openswim) repository if Advisories
   are enabled for the repo.
2. **Maintainer contact** — message or email GitHub
   [@llevintza](https://github.com/llevintza) with a clear description, impact,
   and reproduction steps.

You should receive an acknowledgement when practical. We will work with you on
a fix and coordinated disclosure when needed.

## Safe harbor

Good-faith research that follows this policy and avoids privacy violations,
destructive testing, or data exfiltration is appreciated. Do not access data
that is not yours; swimmer and guardian information must be treated as sensitive
PII.
