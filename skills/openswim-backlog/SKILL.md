# OpenSwim backlog

## When to use

- User asks to implement a roadmap/MVP item
- Need to find the right epic/feature/task ID
- Scope questions about what is in Phase 0–5

## Instructions

1. Read [`docs/roadmap.md`](../../docs/roadmap.md) for phase goals.
2. Use [`docs/backlog/epics.md`](../../docs/backlog/epics.md) → [`features.md`](../../docs/backlog/features.md) → [`tasks.md`](../../docs/backlog/tasks.md).
3. Prefer existing task IDs (e.g. `E5-F2-T1`) in commits/PR text when relevant.
4. Do not invent a parallel tracker; update these docs if scope changes and the user wants the backlog updated.
5. Respect Phase 0 limits: scaffold only unless the user asks to bootstrap runtimes.

## MVP reminder

Phase 1 balanced thin slice: org + roster + dual meet timing + live parent results + basic chat. See features marked `mvp` in `features.md`.
