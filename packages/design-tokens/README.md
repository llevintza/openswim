# Design tokens

Shared visual tokens for web and native clients (colors, type, mark geometry).

Keep platform implementations native; this package documents the shared vocabulary only.

## Files

| File | Use |
|------|-----|
| [`tokens.json`](./tokens.json) | Color, type, and mark geometry tokens |

Canonical brand assets (marks, favicons, app icons, lockups, social preview) live in [`brand/`](../../brand/). See [`brand/README.md`](../../brand/README.md) for usage.
